# UI/UX Conventions: Retro vs Modern Dualism

### 1. Dual-Viewport Division
- The interface is split dynamically into two distinct eras:
  - **The Past (Legacy Viewport)**:
    - Accurate Win95/Win98 chrome (bevels, `#c0c0c0` background, MS Sans Serif fonts, sunken border text inputs, 3D buttons).
    - Authentic CRT phosphor scanlines and vignette effect with optional toggle.
    - Retro tooltips and 8-bit sound effects.
  - **The Future (Reincarnated 2026 Viewport)**:
    - Ultra-clean dark glassmorphism, subtle gradients, Tailwind CSS, Lucide SVG iconography.
    - Real-time reactive data visualizations (interactive SVG charts, responsive layouts).
    - Silky smooth 60fps transitions and accessible focus rings.

### 2. The Central Bridge (Lockstep Control Center)
- Positioned between both viewports:
  - Synchronized cursor indicators.
  - Interactive "Simulate Chaos / Drift" button to demonstrate Kiro's real-time detection & auto-healing capabilities.
  - Live state telemetry radar.
