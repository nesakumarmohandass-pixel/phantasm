# PHANTASM: Autonomous Code Reincarnator & Dual-State Time Machine
## System Architecture & Steering Rules

### 1. Vision & Core Philosophy
PHANTASM resurrects abandoned, legacy, and rotting software (1980s Turbo Pascal, 1990s Visual Basic 6, 2000s Macromedia Flash) into high-performance, modern, reactive 2026 web applications while maintaining mathematical and state parity.

### 2. Core Pillars
1. **Zero Logic Loss**: No heuristic or guessing for business calculations. Every formula must be decompiled into explicit mathematical specifications before code generation.
2. **Dual-State Synchronous Mirror**: The legacy emulated application and the modern reincarnated application must maintain real-time bi-directional event bridging.
3. **Parity Sentinel**: Continuous telemetry monitor calculating real-time divergence, execution speedup ratio, and state parity percentages.
4. **Resurrection Heritage**: Honor the aesthetic and historical context of the original software while providing state-of-the-art responsive accessibility.

### 3. Engineering Standards
- **Framework**: React 19 + TypeScript (Strict Type Safety).
- **Styling**: Tailwind CSS + Custom CRT/Win98 Shaders for the retro legacy viewport; modern glassmorphism for the 2026 viewport.
- **State Engine**: Observable lockstep bridge syncing legacy inputs and modern inputs with sub-5ms latency.
- **Decompilation Pipeline**: Abstract Syntax Tree (AST) extraction mapping legacy controls (e.g. `CommandButton`, `TextBox`, `Timer`) to modern React components and hooks.
