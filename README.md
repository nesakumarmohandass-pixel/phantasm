## 🌟 What is PHANTASM?

Every year, critical software in banking, healthcare, logistics, and aerospace decays because migrating legacy systems (Visual Basic 6, Macromedia Flash, Turbo Pascal, COBOL, Fortran) costs billions of dollars and risks breaking undocumented business logic.

**PHANTASM** is the world’s first **Autonomous Code Reincarnation Engine and Dual-State Time Machine**. It ingests dead legacy code, extracts the core mathematical and business invariants into formal **Kiro Specifications** (`.kiro/specs/`), and synthesizes production-grade modern TypeScript / React applications—**running both the legacy emulated system and the modern web application side-by-side in real-time lockstep to mathematically prove 100.00% behavioral parity.**

---

## ⚡ The World-First Innovation: Dual-State Lockstep Mirror

Unlike static code converters or generic LLM rewrites:
1. **Sub-5ms Bidirectional Mirror:** Type or adjust values in the 1998 Windows 98 dialog, and the 2026 glassmorphic modern app updates in lockstep. Interact with the modern app, and the legacy retro app mirrors the update.
2. **Parity Sentinel:** Continuous telemetry monitor checking numerical drift ($|Y_{legacy} - Y_{modern}|$) and state parity.
3. **Chaos Injection & Auto-Healing:** Click *"Induce Chaos"* to simulate a subtle floating-point drift or migration defect; the Sentinel trips the alert, invokes the Kiro Agent Hook (`.kiro/hooks/on-drift-detected.json`), and automatically synthesizes a hot-patch to restore 100% parity.

## 🚀 Getting Started

### Prerequisites
* Node.js v20+ (Tested on Node v26)
* npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/kiro.git
cd kiro

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:5173` to explore the dual-state time machine.

### Building for Production
```bash
npm run build
npm run preview
```
